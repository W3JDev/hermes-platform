How to use env-vault from a service: 
curl -H "Authorization: Bearer $TOKEN" $ENV_VAULT_URL/api/vars/MINIMAX_API_KEY
# {"name":"MINIMAX_API_KEY","value":"...","scope":"shared","updated_at":1234}
Web UI features:
  • Search filters by name in real time.
  • Scope filter shows only shared or per-profile vars.
  • Click a masked value to reveal (and re-mask on second click).
  • Double-click a row to edit the value or scope.
  • Delete is irreversible — confirm in the modal.
